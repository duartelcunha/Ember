# Security

## Supported release

Security fixes target the latest stable Windows release. macOS and Linux have not passed
native qualification and are not supported releases.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/duartelcunha/Ember/security/advisories)
to contact the maintainer. Include the Ember version, affected platform, impact and a
minimal reproduction. Do not put credentials, private prompts or customer data in the
report. Public issues are suitable for ordinary bugs without security-sensitive details.

The current trust boundaries and known limitations are recorded in the
[threat model](docs/threat-model.md).
